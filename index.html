Freight cars

One row per car. The type code (XM, RS, TM…) is what waybills match on. "Return empty to" is printed on the card.

Paste from a spreadsheet

Copy the rows from Excel, Google Sheets or a JMRI car export and paste them here. A header row helps (Road, Number, Type, Description, Return to), but plain rows in that order work too.

Industries and places

Optional. Where cars go: the car types each spot takes and what it receives or ships. These feed the waybill maker (Pro) and the place list when you write waybills by hand.

4-cycle waybills

Each waybill has four moves, one per session. They match car types, not single cars: any XM waybill can ride in any XM car card.

Print

In the print window set Scale: 100% (or "Actual size"). The bar at the bottom of each sheet should measure exactly 1 inch. Card stock (65–110 lb) folds and lasts best.
